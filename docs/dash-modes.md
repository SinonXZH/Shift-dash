# 冲刺行为模式存档

切换入口：F1 → 冲刺行为模式 → 应用并保存。模式选择随调试设置保存。

## 自由冲刺（旧模式存档）

保留修改前的完整规则：不合拍执行普通冲刺，普通合拍和完美合拍都执行爆发冲刺。

默认普通冲刺速度 1500 像素/秒，持续 0.16 秒、距离 240 像素、冷却 0.35 秒。爆发速度为 1.8 倍，持续约 0.089 秒，距离仍为 240 像素，冷却 0.20 秒。完美窗口 ±0.10 秒，合拍窗口 ±0.20 秒。爆发强化拖尾、角色拉伸、收束光环和确认音；完美使用金色和更亮的和弦。

同一个拍点只奖励一次；旧模式在同拍重复输入时仍可执行普通冲刺。以上数值继续由 F1 调整，切换模式不会重置数值。

## 节奏限定（无减速存档）

| 输入判定 | 行为 |
| --- | --- |
| 不合拍 | 不冲刺，不新增冷却或无敌保护 |
| 普通合拍 | 普通速度、普通时长、普通冷却；播放普通合拍确认音 |
| 完美合拍 | 爆发速度、缩短冷却、强化视觉和完美确认音 |

同一拍只允许一次成功冲刺；已经普通合拍冲刺后，不能通过同拍再次输入升级为完美。跳过拍点不影响后续拍点。冷却中或正在冲刺时不接受新冲刺，也不自动延迟到下一拍。

两个模式共用原有移动、碰撞与伤害规则。判定分支独立保存在 `scripts/dash_behavior.gd`，以后可继续增加模式而不复制玩家移动代码。

## 节奏限定＋碰敌减速（当前默认模式）

保留上一版的输入规则：不合拍不冲刺，普通合拍使用普通冲刺，完美合拍使用爆发冲刺。

新增命中差异：普通冲刺命中敌人后，该次冲刺剩余时间内的速度降至当前速度的 45%；连续命中会叠加减速，最低保留普通初始速度的 15%。剩余持续时间不延长，因此实际冲刺距离会缩短；下一次成功冲刺恢复正常初速。敌人仍会被击杀。

完美冲刺命中敌人不会减速。实心障碍仍会阻挡任何冲刺，危险区域仍按原规则造成伤害。

F1 的“普通冲刺每次碰敌保留速度倍率”可调节减速强度，1 表示不减速。旧的“节奏限定（无减速存档）”和“自由冲刺（旧模式存档）”均可在行为模式中切回，不受该减速参数影响。
