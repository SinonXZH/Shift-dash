# 节奏核心循环重构待办

目标是在保持现有关卡、操作和冲刺手感的前提下，让新内容可以围绕同一条节奏时间线配置和扩展。按系统逐步迁移，每一步都用现有关卡验证。

- [ ] 建立体验基线。记录现有房间顺序、各房间节奏段与预备拍、冲刺判定与命中减速、清怪开门、镜头构图，以及暂停、重开和切房行为。用现有冒烟测试和 F5／F6 试玩覆盖这些路径。

## 1. 节奏与音频管理系统（首个里程碑）

- [ ] 支持为每个 MusicSection 单独配置 Dash 声音，让关卡编辑者可以在检查器中选择音效，切换音乐段时使用对应的 Dash 声音。
- [ ] 定义节奏段数据。用同一份 Godot Resource 描述 BPM、预备拍数、循环拍数和冲刺拍点，迁移 `RhythmGuide` 的三个现有节奏段，保留其拍点和伴奏。
- [ ] 拆分节奏判定与音频播放职责。节奏管理器提供当前拍位、下一拍预览、最近可判定拍及稳定的拍点标识。音频管理器负责播放、音量、延迟补偿与暂停恢复，并提供跨循环连续的播放时间。
- [ ] 迁移现有调用。把 `main.gd` 中的节奏与播放状态协调交给管理器，将 `BeatAudio` 的合成循环和冲刺确认音接入音频层。节奏提示环和冲刺判定读取同一时间线，保留 F1 中已有的节奏与音频调节。
- [ ] 验收。预备拍只在节奏段启动时播放，循环边界前后判定连续，同一拍只奖励一次。验证暂停恢复、重开、切房和命中减速时，音频、提示环和判定保持现有表现。新增一个节奏段时，只需创建资源并让房间引用它。

## 2. 镜头调度系统

- [ ] 把当前固定构图作为默认镜头配置，明确房间的镜头位置、缩放和可见范围由谁控制。
- [ ] 建立统一的镜头请求入口，支持随房间加载应用配置，并允许内容在指定拍点请求镜头变化。定义请求被覆盖以及切房、重开时的复位规则。
- [ ] 验收。现有房间的默认构图一致。配置了节拍镜头的房间可以在循环中按预期触发，退出房间后镜头状态正确复位。镜头变化期间，鼠标指向仍与冲刺方向一致。

## 3. 关卡设计系统

- [ ] 保留 Godot 2D 编辑器摆放房间的流程和现有 `PlayerSpawn`、`Enemies`、`Exit` 结构。把节奏段、难度和可选镜头配置集中到房间检查器。
- [ ] 为房间提供可选的拍点事件配置，明确事件发生在哪一拍、是否随循环重复，以及重开时如何复位。用一个节拍触发的镜头变化验证配置流程。
- [ ] 提供可复制的房间模板，检查必需节点和资源引用，更新现有的关卡编辑指南。
- [ ] 验收。复制模板后，可以在检查器里摆放敌人与道具、选择节奏段、配置拍点事件，再按 F6 试玩，并加入 F5 的房间流程。现有房间仍按原顺序通关。

## 4. 显眼的鼠标位置显示

- [ ] 增加带对比描边的瞄准准星，保持屏幕尺寸稳定。准星以实际鼠标位置为准，与冲刺使用的瞄准方向一致。
- [ ] 设置准星与系统鼠标在游玩、暂停和 F1 面板中的显示规则，保留原有点击操作。
- [ ] 验收。在明暗背景、特效叠加、窗口缩放和镜头变化时都能快速找到准星。右键冲刺、Shift 冲刺和菜单点击保持原有行为。

实施顺序为 **体验基线 → 节奏与音频 → 镜头 → 关卡配置 → 准星验收**。准星样式可以提前制作，最终随镜头和输入一起验证。
