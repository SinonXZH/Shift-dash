# Shift-dash
A top-down 2D action game exploring 360° dashing as a core mechanic for combat, evasion, and movement. Made with Godot 4 for GitHub Game Off 2026.

关卡已拆分为房间、玩家、敌人、出口和 UI 场景，可直接在 Godot 编辑器中布置。详见 [关卡编辑指南](docs/level-editing.md)。打开房间场景后按 F6 单独试玩，F5 运行完整流程。

按 F5 运行游戏，Shift / 鼠标右键向鼠标方向冲刺。高音敲击对应呼吸环的冲刺拍点；每个房间使用不同节奏，鼓点由代码合成，无需外部音频素材。呼吸环与判定使用音频播放时钟，循环鼓点会随暂停一起停止推进。

按 F1 打开调试设置，可修改 BPM、鼓点音量、节奏校准和冲刺参数，也可禁用普通移动。正值校准让提示相对音频提前，负值让提示延后。修改 BPM 后重新倒数；音量设为 0 时仍保留节拍运行。

默认使用节奏限定模式：不合拍不冲刺，普通合拍执行普通冲刺，完美合拍执行 1.8 倍速度的爆发冲刺。两种冲刺距离均为 240 像素，默认冷却分别为 0.35 秒和 0.20 秒。完美冲刺保留强化光带、角色拉伸和独立确认音。F1 可切回“自由冲刺（旧模式存档）”，规则详见 [冲刺行为模式存档](docs/dash-modes.md)。

当前默认启用“节奏限定＋碰敌减速”：普通冲刺每次命中敌人后保留当前速度的 45%（最低 15% 初始速度），剩余冲刺时间不延长；完美冲刺命中不减速。F1 可调整倍率，或切回上一版无减速模式。
